# Competitive Landscape — Handbooks & Books in the Category

Research snapshot, July 2026. For marketing/positioning use — never for in-book
comparison (self-comparison in the book itself reads as insecure).

## The field

**Executive / business-leader books:**
| Title | Author(s) | Notes |
|---|---|---|
| *Agentic Artificial Intelligence* (2025) | Pascal Bornet + 10 co-authors | The heavyweight: 550 pp, Forbes Top-10 Tech Book, McKinsey/Microsoft Research pedigree. Framework + case-study anthology. |
| *Untangling AI* (Wiley, Feb 2026) | Matt Kesby | Only mainstream-publisher 2026 release for non-technical executives. 464 pp. |
| *AI First* | Brotman & Sack | Ex-Starbucks/Microsoft exec perspective. |

**Technical / builder books:**
- O'Reilly: *Building Applications with AI Agents* (Albada), *Building Agentic
  AI* (blueprints), *AI Agents: The Definitive Guide* (upcoming ~Sep 2026 —
  state machines, HITL, swarms), *AI Agents in Practice*.

- Leanpub: *The Agentic AI Book* (engineering guide).
- Academic: *The Agentic AI Handbook* (Kaushik Bar, SSRN).

## Clawable's six differentiators (nobody else has any of these)

1. **Logged production evidence** — session files, timestamps, evidence tags
   against a live system. Others retell case studies; this is the transcript.
2. **Dual-track, same universe** — business + builder editions describe the
   same running system from two altitudes, cross-linked.
3. **The book proves its own thesis** — written/edited with the agents it
   describes; public revision history. "The only handbook in the category
   with an audit trail."
4. **Reproducible** — FlowWink is open source; the reader can run the same
   experiments today. No other book ships a runnable reference implementation.
5. **The operator perspective** — everyone teaches building agents; nobody
   documents *running* one for months (drift, stagnation, mandates, quiet
   proofs). Unowned ground.
6. **Freshness** — covers June 2026 events; print is 12–18 months behind.

## Positioning line

Don't position against the books — position against the category:

> *"There are excellent books about what agents could do.
> This is the logged report of what one did."*

Bornet wins the airport shelf. Clawable wins the reader who wants receipts.
